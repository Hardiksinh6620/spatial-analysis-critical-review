# Mean center

For unweighted two-dimensional points, the mean center is `(mean(x), mean(y))`. A weighted version uses a positive total weight and documents what each weight represents. It answers a different question from finding the middle observation or the most accessible location.

Use coordinates with an appropriate distance interpretation. The educational example in this repository uses synthetic Cartesian coordinates; it does not select a projection or model the Earth's surface.

Moving every input by the same vector should move the mean center by that vector. A very distant point can move the center appreciably, so examine the input distribution before interpreting the result.

Source context: original report, PDF page 5. Formula reference: [Esri Mean Center](https://pro.arcgis.com/en/pro-app/3.4/tool-reference/spatial-statistics/h-how-mean-center-spatial-statistics-works.htm).
